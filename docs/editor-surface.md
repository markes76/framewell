## Boundaries

This iteration improves the workspace and durable guide workflow. It does not establish Snagit feature parity. Guided vertical scrolling extends the capture selector with a preview, an explicit selection and floating Finish/Cancel controls. Automatic/horizontal scrolling, OCR, crop/resize handles, stamps, richer effects, JEV and OpenAI image generation remain release gates. Preserve the independent Swift installation and library.

## Step-tool rebuild contract (13 October 2026)

The user rejected drag-to-place steps and missing Snagit-style settings. This code-led expansion keeps the canvas-led desktop shell, replacing the step interaction with one-click centered markers, next-marker preview, numeric/upper/lowercase sequences, restart/start value, shape, size, text/fill/border controls and saved reusable styles. Existing markers remain editable through Move. The main controls must be discoverable in a compact inspector; advanced saved styles may scroll at the minimum window size. Undo restores the next sequence from the remaining markers.

Visual finish: calm white controls with teal selection, bolder marker labels, consistent six-point control corners. Guides gain original generated editorial artwork in their workspace and portable HTML export; artwork supplements real screenshot content and never substitutes for it. This is an improvement to the prototype, not a full Snagit parity claim. No generated UI comp; the installed Snagit Step tool and official Step Tool documentation are functional references only.

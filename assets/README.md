# Asset origins

`framewell-guide-cover.png` is original artwork generated with OpenAI image generation for this project on 13 October 2026. The exact prompt is in `framewell-guide-cover.prompt.txt` and embedded in PNG metadata. It illustrates guide-making and contains no TechSmith artwork. It is bundled in the guide workspace and HTML guide export.

`Ubuntu-Bold.ttf` comes from the official Google Fonts repository: https://github.com/google/fonts/blob/main/ufl/ubuntu/Ubuntu-Bold.ttf . It is used for step markers and their previews. The existing Ubuntu font and this bold face are covered by `UFL.txt`; their license is separate from the code's MIT license.

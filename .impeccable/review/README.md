# Screenshot provenance

These are actual VMPal captures of the original Framewell Rust desktop app on 13 October 2026. The screenshot tool captured only the app rectangle; pixels were saved unchanged. `editor-desktop.png` shows the normal 1380-point window; the three minimum captures show the 1100-point window.

Image content is the original synthetic software screen rendered by `framewell::sample()` and the original synthetic demo from the earlier alpha. Arrows were drawn through the app UI. No commercial application artwork, external account pages, private capture content or secrets appear in these images. They are build/review evidence, not generated design mockups or a claim of feature parity.
